# Cat Cursor Chase

添付の猫スプライトシートを使った、canvas製の小さなWebアプリです。ブラウザ上で猫がマウスカーソル、スマホではタップ位置をゆっくり追いかけます。

## ファイル構成

- `index.html`: アプリ本体のHTML
- `style.css`: 画面全体とステータス表示のスタイル
- `main.js`: canvas描画、移動、アニメーション制御
- `assets/cat_sprite.png`: 読み込む猫スプライトシート
- `assets/cat-teaser-cursor.svg`: アプリ内で使う猫じゃらしカーソル

## 使い方

`index.html` をブラウザで開くと動きます。ローカルサーバーは必須ではありません。

動作:

- マウス移動、またはスマホのタップ位置へ猫が移動します。
- 移動中は `run` アニメーションを再生します。
- 止まると `idle` の座り画像になります。
- 30秒操作がないと `sleep` アニメーションをループします。
- クリック、またはタップすると `wave` アニメーションを再生します。
- 画面端に近づくと `box` の段ボール箱画像を表示します。
- 左へ進むときは猫画像を左右反転します。

## フレーム座標の調整方法

`main.js` の `SPRITE_CONFIG.animations` に、スプライトシートから切り出す座標をまとめています。

```js
run: [
  { x: 38, y: 162, w: 160, h: 118 }
]
```

各値の意味:

- `x`: スプライトシート左上からの横位置
- `y`: スプライトシート左上からの縦位置
- `w`: 切り出す幅
- `h`: 切り出す高さ

座標はまず仮で入れています。猫以外の文字や余白が入る場合は、該当アニメーションの `x`, `y`, `w`, `h` を少しずつ調整してください。

アニメーション速度は `SPRITE_CONFIG.fps` で変更できます。
